Conventions. *Fit*: the top-level scalar value in fit.json (`not a fit key` when absent). *Meaning*: prefix `A4:` (the register's "What it does", followed by the config.py comment when the A4 text continues the row above it; `[A4 row value X]` when the A4 row names a value other than fit.json's), `config.py:N:` (the OPTIONS comment at line N: the inline comment, else the comment block above it), or `core-v2:` (section-4 text). *RTL*: a case-insensitive whole-word grep of the rule name over the RTL files; the hits are almost all comments naming the rule beside the logic that implements it (file:line, at most six lines per file shown, total count first); `macros` lists the build macros in v35_macros.svh whose description names the rule. *Bucket*: the section-4 list the item appears in, with the bracketed module for (b); "also in" names other section-4 lists that name the same rule.
